Media Ad Skip

播到广告段，自动跳到正片。

只管 B站、抖音网页版：片内恰饭 seek 过去，信息流广告/直播可划走。开源本地装，不上传观看记录。

下载扩展 ZIP 改用油猴 读取版本…

安装

先点上方「下载扩展 ZIP」。解压后，最终要选中直接含有 manifest.json、background.js、content/ 的那一层（常见文件夹名 extension）。

  1. 下载并解压

    点本页「下载扩展 ZIP」。Windows 可右键 ZIP →「全部解压」到例如 D:\Apps\media-ad-skip。不要只打开压缩包窗口里用，必须解压到真实文件夹。

    进解压目录后确认能看到这些（名字可能在子文件夹 extension 里）：

    • manifest.json（必有）
    • background.js、content/、popup/、icons/
  2. 打开扩展管理页

    在地址栏原样输入并回车（复制粘贴即可）：

    • Chrome：chrome://extensions
    • Edge：edge://extensions
    • Brave：brave://extensions
    • Opera：opera://extensions
    • Vivaldi：vivaldi://extensions
  3. 打开开发者模式

    页面右上角打开「开发者模式 / Developer mode」开关。关掉时看不到「加载已解压」按钮。

  4. 加载文件夹

    点「加载已解压的扩展程序 / Load unpacked」。在文件对话框里进入解压后的目录，选中直接含 manifest.json 的那一层，再点「选择文件夹」。

    成功后列表会出现 Media Ad Skip，开关为开启。点浏览器工具栏拼图图标，找到它并「固定」，方便以后点。

  5. 验证是否生效

    新开一个标签，打开 bilibili.com 任意视频页，或 douyin.com。点工具栏扩展图标：应能看到自动跳过等开关。播放时若命中广告段，右下角会出现 toast（可撤销）。

最常见翻车：选成了仓库根目录（外面那一层只有 README，没有 manifest.json）。必须再往里进一层，选到 extension。

  1. 版本与解压

    需要 Firefox 121 或更高（菜单 → 帮助 → 关于 Firefox 可看版本）。下载 ZIP 并解压到固定位置，例如 D:\Apps\media-ad-skip\extension。临时加载依赖这个路径，别解压完就删。

  2. 打开调试页

    地址栏输入 about:debugging#/runtime/this-firefox 回车。这是 Firefox 的临时扩展入口（不是 about:addons）。

  3. 临时载入

    左侧或页面里点「临时载入附加组件 / Load Temporary Add-on…」。在文件选择器里进入解压目录，选中 manifest.json 这个文件（不是选文件夹）。

    载入成功后，本页列表会出现 Media Ad Skip。可到工具栏固定图标。

  4. 去网站试用

    打开 B站视频页或抖音网页，点扩展图标确认面板出来。若没反应：回到调试页确认扩展还在，关掉旧标签再新开一次。

  5. 重启后怎么办

    Firefox 临时附加组件关浏览器就会卸掉。下次打开 Firefox，再走一遍「调试页 → 临时载入 → 选同一份 manifest.json」即可。路径别改，会省事很多。

若提示不支持 service_worker：升级到 121+。本包已同时声明 background.scripts，新版 Firefox 可直接用。

  1. 先装脚本管理器

    任选其一（商店搜索安装即可）：

    • Tampermonkey（Chrome / Edge / Firefox 都常见）
    • Violentmonkey（开源替代）

    装好后工具栏会出现管理器图标。确认它对当前浏览器已启用。

  2. 安装本脚本

    回到本页，点上方「改用油猴」。浏览器会打开脚本源码页或弹出安装确认。在管理器对话框里点「安装 / Install」。

    若只打开了源码没有安装按钮：在管理器里新建脚本，把源码全文粘贴保存；或从仓库打开 media-ad-skip.user.js 用「Raw」再装。

  3. 确认匹配站点

    打开管理器 → 找到 Media Ad Skip → 确认已启用。脚本应匹配 bilibili / douyin 相关页面（含 bangumi、稍后再看、手机站等）。

  4. 试用

    新开 B站或抖音标签。管理器图标上通常会显示「有脚本在跑」。播放含恰饭段的视频时会自动 seek；也可在管理器菜单里找相关命令（若有注册）。

  5. 更新

    脚本写了 @updateURL。Tampermonkey 会定期检查；也可在管理器里对该脚本点「检查更新」。一般不用手动再下 ZIP。

油猴更省事（不用开发者模式）。扩展则有独立设置页、更新角标、信息流等开关更集中。两套核心逻辑同源，装一种即可。

以后怎么更新（扩展）

「加载已解压」不会像商店扩展那样静默升级。扩展每天查一次 GitHub；有新版时工具栏图标角标显示 ↑，弹窗里也可点检查更新。

  1. 下载新包

    从本页再下最新 ZIP，或打开 Releases 选最新资源。

  2. 覆盖文件

    用新解压出的文件覆盖你当初加载的那个扩展目录（同一路径）。不要另建一份新目录又加载一次，否则会出现两个 Media Ad Skip。

  3. 重新加载扩展

    回到 chrome://extensions（或对应浏览器），在 Media Ad Skip 卡片上点「重新加载 / Reload」圆形箭头。

  4. 刷新网站标签

    关掉所有旧的 B站 / 抖音标签，再新开。只刷新有时仍跑旧 content script。

常见问题

加载时报错 / 找不到 manifest？
选的文件夹不对。在资源管理器里打开该文件夹，确认第一层就有 manifest.json。Release 解压后通常是 …/extension/；若下的是整个仓库 ZIP，还要再进一层 media-ad-skip/extension/。
扩展在列表里，打开视频却没反应？
① 确认网址是 bilibili.com / douyin.com（其它站不会注入）。② 扩展页点重新加载。③ 关掉旧标签再新开。④ 点扩展图标看开关是否开启「自动跳过」。
抖音页面卡顿、发烫？
打开扩展「选项」，先关掉「信息流广告 / 直播卡 / 购物卡」划走；尽量进具体视频页再测。首页推荐流 DOM 重，划走逻辑更吃性能。
误跳了正片怎么办？
右下角 toast 点「撤销」可 seek 回去；也可对本集开「本集不跳」。觉得某段标错了，可用「标错了」记到本地反馈。
支持手机 App 或其它视频站吗？
不支持。只做 B站与抖音网页版。
会不会上传我的观看记录？
不会。设置存在浏览器本地；会访问的公开接口包括 SponsorBlock、B站公开 API、GitHub 版本检查。详见 隐私说明。
