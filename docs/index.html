Media Ad Skip

B站 / 抖音网页版，自动跳过片内恰饭与信息流广告。未上架商店，按下面三步装上即可。

下载扩展 ZIP 装油猴脚本 读取最新版本…

怎么装

先下 ZIP 解压；目录里要直接看到 manifest.json。

  1. 下载 ZIP 并解压。记住解压后的文件夹位置。
  2. 打开扩展页：Chrome chrome://extensions · Edge edge://extensions · Brave / Opera / Vivaldi 同理，打开开发者模式。
  3. 点「加载已解压的扩展程序」，选中含 manifest.json 的那一层（通常叫 extension）。
  4. 打开 B站或抖音网页，点工具栏图标即可用。

选成仓库根目录会失败。必须选里面直接有 manifest.json 的文件夹。

  1. 需要 Firefox 121+。下载并解压 ZIP。
  2. 打开 about:debugging#/runtime/this-firefox。
  3. 「临时载入附加组件」→ 选解压目录里的 manifest.json。
  4. 打开 B站 / 抖音网页使用。浏览器重启后需再载一次。
  1. 安装 Tampermonkey / Violentmonkey 等脚本管理器。
  2. 点上方「装油猴脚本」，在管理器里确认安装。
  3. 打开 B站 / 抖音页面；脚本带 @updateURL，管理器会抽查更新。

油猴适合不想碰「开发者模式」的用户；扩展功能更完整（设置页、更新角标）。

以后怎么更新

本地加载不会静默升级；扩展会每天查 GitHub，有新版图标角标显示 ↑。

  1. 从本页或 Releases 再下最新 ZIP。
  2. 用新文件覆盖本地扩展目录，扩展页点「重新加载」。
  3. 关掉旧的 B站 / 抖音标签再开。

装不上？

扩展在，页面没反应
确认是 bilibili.com / douyin.com；重载扩展后新开标签。
抖音卡顿
选项里先关掉「信息流广告 / 直播卡」，尽量进具体视频页再测。
只覆盖哪些站？
仅 B站与抖音网页版；客户端 App 与其它视频站不做。
