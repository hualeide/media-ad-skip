安装

下载 ZIP 后解压，选中里面直接有 manifest.json 的那一层。

  1. 解压 ZIP，记下文件夹路径。
  2. 打开 chrome://extensions 或 edge://extensions（Brave / Opera / Vivaldi 同理），打开开发者模式。
  3. 「加载已解压的扩展程序」→ 选含 manifest.json 的目录（常见名 extension）。
  4. 打开任意 B站视频或抖音网页，点工具栏图标。

选仓库根目录会失败：那一层通常没有 manifest.json。

  1. Firefox 121+。解压 ZIP。
  2. 打开 about:debugging#/runtime/this-firefox。
  3. 「临时载入附加组件」→ 选目录里的 manifest.json。
  4. 去 B站 / 抖音用。重启浏览器后需再载一次。
  1. 先装 Tampermonkey 或 Violentmonkey。
  2. 点上方「改用油猴」，在管理器里确认安装。
  3. 打开 B站 / 抖音即可；脚本带自动更新检查。

扩展有设置页和更新角标；油猴更省事。

更新

本地加载不会静默升级。扩展每天查 GitHub，有新版图标角标 ↑。

  1. 再下最新 ZIP（本页或 Releases）。
  2. 覆盖本地扩展目录 → 扩展页「重新加载」。
  3. 关掉旧的 B站 / 抖音标签再开。

常见问题

扩展装了，页面没反应？
确认域名是 bilibili.com / douyin.com；重载扩展后新开标签。
抖音卡顿？
选项里先关「信息流广告 / 直播卡」，尽量进具体视频页。
支持 App 或其它网站吗？
不支持。只做 B站与抖音网页版。
