安装

先下 ZIP，再选中直接含 manifest.json 的那一层（常见名 extension）。

不要双开 扩展与油猴脚本二选一。同时开会互相挡版本、重复跳过。
  1. 下载并解压

    点上方「下载扩展 ZIP」。Windows：右键 →「全部解压」到固定目录（如 D:\Apps\media-ad-skip）。不要在压缩包窗口里直接用。

    确认能看到：

    • manifest.json（必有）
    • background.js、content/、popup/、icons/
  2. 打开扩展页

    地址栏输入：

    • Chrome chrome://extensions
    • Edge edge://extensions
    • Brave / Opera / Vivaldi 同理
  3. 开发者模式 → 加载已解压

    右上角打开「开发者模式」，点「加载已解压的扩展程序」，选中含 manifest.json 的那一层。

  4. 验证

    新开 B站 或 抖音 视频页，点工具栏图标。命中广告段时右下角会出 toast（可撤销）。

最常见翻车：选成仓库根目录。没有 manifest.json 就再往里进到 extension。

  1. 版本与解压

    需要 Firefox 121+。ZIP 解压到固定路径，临时加载依赖该路径。

  2. 调试页临时载入

    打开 about:debugging#/runtime/this-firefox →「临时载入附加组件」→ 选 manifest.json 文件。

  3. 试用

    打开 B站 / 抖音视频页，确认扩展图标可用。

  4. 重启后

    临时附加组件会卸掉，按同一路径再载一次即可。

若提示不支持 service_worker：升级到 121+。本包已同时声明 background.scripts。

  1. 安装脚本管理器

    Tampermonkey 或 Violentmonkey（商店搜索安装）。

  2. 安装本脚本

    点上方「改用油猴」，在管理器里确认安装。也可从仓库打开 media-ad-skip.user.js 的 Raw。

  3. 试用与更新

    新开 B站 / 抖音标签验证。脚本带 @updateURL，管理器可检查更新。

油猴更省事；扩展有独立设置页与更新角标。只装一种。

更新扩展

「加载已解压」不会商店式静默升级。有新版时工具栏角标显示 ↑。

  1. 下新包并覆盖

    再下最新 ZIP，覆盖当初加载的同一目录（不要另建一份再加载）。

  2. 重新加载 + 新开标签

    扩展页点「重新加载」，关掉旧的 B站 / 抖音标签再开。

怎么工作的

不改视频文件。B站 / 抖音详情页：检出广告段再 seek；抖音推荐流：认出广告卡就划走。

  1. 注入页面 — 只在 bilibili / douyin 跑；扩展与油猴同源逻辑。
  2. 分流 — 推荐流 ?recommend=1 只划走；/video/ 或弹窗详情才做片内分析。
  3. 划走 — API 标记优先，不够再看 DOM；弹窗直播（正片还在）不划；先滑再轻提示。
  4. 片内 — 看点 / SponsorBlock / 字幕 → 进段则 seek 到段末；可撤销、本集不跳。

常见问题

加载报错 / 找不到 manifest？

文件夹选错了。第一层就要有 manifest.json。整仓 ZIP 需再进 media-ad-skip/extension/。

扩展在，视频页没反应？

确认是 bilibili / douyin；扩展页重新加载；关掉旧标签再开；看「自动跳过」是否开启。

抖音卡顿？

选项里先关信息流划走；尽量进具体视频页再测。

误跳了正片？

toast「撤销」回去；可用「本段不再跳 / 本集不跳 / 标错了」。

会上传观看记录吗？

不会。详见 隐私说明。
