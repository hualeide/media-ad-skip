# Media Ad Skip — 商店上架文案

## 一句话卖点

自动跳过 B站 / 抖音网页版片内广告：社区标注 + 字幕品牌词 + 一键撤销。

## 简短介绍（商店描述）

看视频时自动跳过恰饭段。B站优先使用 SponsorBlock 社区标注，并辅以字幕品牌词（如转转、爱回收）与弹幕时间戳；抖音支持官方广告看点与信息流广告划走。误跳可撤销，也可对本集 / 指定 UP 禁用。所有设置保存在本地，不上传观看账号。

## 权限说明（商店问答）

- **读取浏览数据**：仅在 B站 / 抖音页面注入脚本以控制播放进度。
- **storage**：保存开关、品牌词、黑名单与标错反馈。
- **访问 bsbsb.top / bilibili API**：拉取公开广告分段、字幕与弹幕。

## 截图清单（自行截 1280×800 或商店要求尺寸）

1. B站视频页：浮动面板显示「SB n 段」并刚跳过  
2. 跳过后 toast：撤销 / 本集不跳 / 标错了  
3. 扩展设置页：品牌词与黑名单  
4. 抖音长视频：看点广告状态（可选）

本地预览设置页：加载扩展后打开「扩展选项」。
